# Cantalya Nakliye & Lojistik

Cantalya Nakliye & Lojistik'in Türkiye geneli nakliye ve taşımacılık web sitesi.

## Hizmetler

- Parça eşya taşıma
- Paletli yük taşıma
- Parsiyel nakliye ve ambar
- Ticari yük ve sevkiyat
- Evden eve nakliyat

Merkez Antalya, hizmet bölgesi Türkiye genelidir.

## Yerel geliştirme

```bash
npm install
npm run dev
```

`main` dalına gönderilen değişiklikler GitHub Actions ile otomatik olarak GitHub Pages'e yayınlanır.
